## Interpretation and limitations

- The reported `MATCH` fraction is assay-level allele evidence,
  **not genotype concordance** against an independent truth set.
- `VCF_ABSENT` must not be interpreted as homozygous reference.
- `NOT_EVALUATED` is an explicit technical evidence state,
  not evidence of a negative genotype.
- Genotype projection is intentionally restricted to supported
  multiallelic SNV and validated indel scenarios; ordinary
  biallelic SNV projection is not evaluated.
- Assay and candidate counts are technical observations,
  not independent biological replicates.
- These aggregate results do not establish clinical validity,
  variant pathogenicity, or imputation accuracy.

## Reproducibility

The underlying bundles were independently built and verified.
Aggregate counts were generated by calling the read-only
`arrayevidence.qc.summarize_bundle()` function for each
verified bundle, using ArrayEvidence commit `b9b683e`.
The `arrayevidence qc` command exposes the same function.

This document contains no participant-level records, sample
identifiers, genotypes, or genomic coordinates.
